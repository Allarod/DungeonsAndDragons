# Títulos
Cada apartado de título posee una jerarquía basada en el número de "#", siendo 1 la mayor posición y 6 la menor.

# Formatos de texto
Se puede usar con el click derecho + formato/párrafo/insertar, o usando la siguiente simbología:
### Formato

*Cursiva*
~~Tachado~~

`código`
$Fórmula$

# Atajos
- Crtl+E -> Alternar entre el modo edición y vista.
- Crtl+Z -> Deshacer.
- Crtl+Y -> Rehacer.
- Crtl+N -> Nueva nota.
- Crtl+* -> Nueva carpeta.
- Crtl+T -> Nueva pestaña.
- Crtl+B -> Poner negrita.
- Crtl+I -> Poner cursiva.
- Crtl+X -> Cortar para pegar en otro lugar.
